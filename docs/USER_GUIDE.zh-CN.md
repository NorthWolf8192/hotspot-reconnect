# 热点自动重连 · Windows 11 云母版 v3（跟随系统主题）

适用：有无线网卡的 Windows 11 电脑。使用系统自带的 .NET Framework / WPF，无需安装 Python。双击 HotspotReconnect.exe 即可启动。

## 云母界面

- 使用 Windows 原生 DWM 云母材质（DWMSBT_MAINWINDOW），保留原生标题栏、圆角、窗口缩放和贴靠行为。
- 托盘右键菜单使用独立的 WPF 窗口，并为这个窗口调用同一套原生 DWM 云母接口；菜单布局、图标、悬停及键盘交互由程序实现。它会跟随浅色、深色主题，支持点击外部关闭、Esc 关闭、上下方向键选择、Enter 执行。菜单会根据当前显示器工作区域调整位置。
- 新图标采用蓝色渐变圆角方形与白色 Wi-Fi 符号。程序文件、窗口标题栏、任务栏、托盘、主窗口及右键菜单统一使用该图标，包含 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 像素九档图标资源。
- 云母接口需要 Windows 11 22H2（内部版本 22621）或更新系统。较旧系统可使用同主题的纯色背景，Windows 10 也会回退为纯色。
- 界面跟随系统应用的浅色、深色主题，支持运行中切换，并为高对比度模式使用系统颜色。
- 默认始终跟随 Windows 的应用颜色模式，无需在程序中选择主题。通过系统偏好变化通知和原生窗口消息更新，主窗口、标题栏、已打开的托盘菜单及云母背景同步切换。主窗口隐藏到托盘时也会更新；打开窗口、打开菜单和电脑唤醒时会再次读取系统设置，补齐错过的通知。没有主题轮询，不会因主题变化检查或连接 Wi-Fi。
- 使用圆角卡片、蓝色主按钮、热点下拉列表、自动启动开关和活动记录区域。
- 云母是融合桌面壁纸色调的柔和背景，不会像磨砂玻璃一样清晰透出后方窗口。系统透明效果设置、省电状态及远程桌面等环境可能使它使用纯色回退。
- 附带的浅色、深色布局预览使用纯色底图，便于查看控件布局；实际云母背景由 Windows 桌面合成器渲染。

## 第一次使用

1. 如果旧版还在运行，请先右键任务栏右下角的旧版托盘图标，选择“退出程序”。
2. 先用 Windows 的 Wi-Fi 菜单成功连接一次手机热点，让 Windows 保存连接信息和密码。
3. 把新版文件夹放在准备长期存放的位置，双击其中的 HotspotReconnect.exe。
4. 在列表里选中手机热点，点击“启用唤醒重连”。找不到热点时，先在 Windows 中连接一次，再刷新列表。
5. 如果希望每次登录电脑后自动运行，打开“登录后自动启动”开关。如果旧版已经启用过，请在新版中关闭后重新打开一次，把自动启动位置更新为新版。

程序会沿用旧版保存在当前用户设置目录里的热点选择和启用状态。启用后请保持程序位置不变；需要移动时，先取消自动启动，移动并打开新位置的程序，再重新勾选。

## 现在的工作方式

- 只监听 Windows 的睡眠及休眠恢复通知，没有定时轮询，也没有连续重试。
- 收到唤醒通知后，先等待 5 秒，让无线网卡和系统网络服务恢复，再检查一次所选无线网卡。
- 如果网卡断开，就向 Windows 请求连接一次已选择的手机热点。
- 如果网卡已经连上任意 Wi-Fi，或者 Windows 正在连接、验证，就交由系统处理。本次不提交新的连接请求，也不再补查。
- 如果网卡仍未就绪、没有找到网卡、手机热点不可用或连接失败，本次结束。需要补查时可以手动点击“立即检查”，下一次唤醒也会再次检查。
- 点击“启用唤醒重连”或登录后启动程序时，只启用唤醒监听，不自动执行连接检查。
- “立即检查”会立即执行一次检查；如有尚未执行的唤醒检查，会先取消它，避免重复操作。
- “暂停唤醒重连”会停用功能，取消尚未执行的唤醒检查，并保存暂停状态。
- 关闭窗口或最小化后，程序留在任务栏右侧的托盘里。双击托盘图标可打开窗口，右键可暂停或退出；图标可能收在向上箭头里。
- “退出程序”停止本次运行，但保留启用状态。若希望下次打开也保持暂停，请先点击“暂停唤醒重连”。

“已请求连接”仅表示连接请求已经交给 Windows，不表示已经连接成功。程序不会持续更新连接状态，请在 Windows Wi-Fi 菜单确认最终结果。“已连接 Wi-Fi”只表示所选网卡的连接状态，不表示已经验证连上目标热点或可以上网。

## 如何验证

1. 选择手机热点并启用唤醒重连，让程序留在托盘中运行。
2. 将电脑睡眠或休眠，再让手机离开。
3. 回来时先确认手机热点已开启，再唤醒电脑。
4. 等待约 5 秒后，在程序窗口查看本次检查提示，在 Windows Wi-Fi 菜单确认最终连接结果。
5. 如果网卡恢复较慢或手机热点稍后才打开，可点击一次“立即检查”。程序本身不会反复重试。

仅锁屏、打开窗口、手机热点重新出现，不会触发自动检查。电脑关机后重新登录时，程序也只恢复监听；需要当时连接可点击“立即检查”。Windows 的自动唤醒也可能触发一次检查。程序必须在当前用户会话中运行，才能收到唤醒事件。

## 手机与连接设置

- 程序只能操作电脑的 Wi-Fi，不能远程开启手机热点。手机如设置了无设备连接时自动关闭热点，需要关闭该设置，或回来后先重新打开热点。
- 手机热点名称或密码改变后，请先在 Windows 中手动连接成功，再在程序里刷新并重新选择。
- Wi-Fi 关闭、飞行模式、无线驱动故障等情况可能需要手动处理。程序不会重启网卡或修改其他 Wi-Fi 的优先级。
- 程序不扫描周边网络，不读取、导出或保存 Wi-Fi 密码，使用 Windows 已保存的无线配置请求连接。
- 程序没有上传数据或联系外部服务器的功能。界面日志仅保留在本次运行的内存中。

## 设置位置与移除

- 热点配置名称、网卡标识和启用状态：当前用户的 `%LOCALAPPDATA%\HotspotReconnect\settings.xml`，不包含密码。
- 自动启动：主动勾选时，在当前用户的 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下写入 `HotspotReconnect` 项。通常不需要管理员权限；组织策略可能限制此设置。
- 移除时先关闭“登录后自动启动”开关，再从托盘退出，删除程序文件夹即可。需要完全清理时，可一并删除上述设置文件夹。

已完成编译、无线接口结构布局检查，以及 39 项逻辑、模拟事件、主题切换和布局断言，覆盖仅唤醒触发、启用时不检查、延迟调度、重复通知不重复检查、每次唤醒只读一次网卡状态并最多连接一次、暂停及再次睡眠取消待执行检查、下一次唤醒重新触发、退出取消、网卡选择、中文配置保存、菜单命令仅执行一次、Esc 取消、方向键导航及多显示器边缘位置计算。主题测试使用可替换的系统主题读取器模拟系统切换，验证后台通知回到界面线程、已打开菜单同步、隐藏主窗口同步、原生窗口深色属性以及主题变化不触发 Wi-Fi 操作。没有修改用户的 Windows 主题设置。模拟唤醒测试使用可控制的等待任务，生产程序等待时间为 5 秒。主窗口和菜单均已检查浅色、深色布局，原生云母设置及客户区扩展接口均返回成功（HRESULT 0）。

构建环境无法访问真实无线网卡，尚未完成真实电脑睡眠及唤醒的实机测试；实际用户桌面的窗口截图验证也未完成。请首次使用时按上方步骤验证本机显示和连接效果。

源码包括 HotspotReconnect.cs（无线连接与设置）、App.cs（窗口和事件处理）、MainWindow.xaml（主界面样式）、TrayMenu.cs 与 TrayMenu.xaml（云母托盘菜单）、Tests.cs（回归检查）、app.manifest（系统兼容与缩放声明）。AppIcon.svg / AppIcon.png / AppIcon.ico 是图标资源。build.ps1 使用系统自带的 .NET Framework 编译器重新生成程序，并将全部界面和图标资源嵌入程序。正常使用只需要 HotspotReconnect.exe。
