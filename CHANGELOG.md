# Changelog

## 1.0.0 — 2026-11-06

Initial public release.

- One saved-hotspot connection check per sleep or hibernation resume, after a five-second delay.
- Manual checks, pause/resume, tray operation, and optional startup at sign-in.
- Native Windows 11 Mica main window and tray menu, following the system app theme.
- Original multi-resolution Wi-Fi icon and Chinese/English documentation.
- Windows build automation, headless core checks, and optional interactive desktop checks.
